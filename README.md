**Talkspace** — современный веб-форум для обмена мнениями, идеями и знаниями. Платформа создана для комфортного общения по различным темам, от политики до видеоигр.

## Основные возможности

### 🏠 Главная страница
- **Лента постов** — все публикации в хронологическом порядке
- **Система тегов** — категоризация по темам
- **Активные обсуждения** — самые популярные посты
- **Адаптивный дизайн** — удобство на всех устройствах

### 🔍 Умный поиск
- Поиск по тексту публикаций
- Фильтрация по тегам/категориям
- Поиск по автору
- Быстрые результаты с подсветкой

### 📝 Создание контента
- **Публикация постов** — с поддержкой форматирования
- **Система тегов** — выбор категорий при создании

### 👤 Личный профиль
- **История публикаций** — все ваши посты в одном месте
- **Лайкнутые посты** — сохраненные для быстрого доступа
- **Подписки** — список интересующих авторов
- **Комментарии** — все ваши участия в обсуждениях

### 💬 Система обсуждений
- **Комментарии к постам** — многоуровневые обсуждения
- **Лайки** — оценка контента
- **Ответы на комментарии** — ветвление дискуссий

### 🏷️ Категории (теги)
- **Политика** — обсуждения политических тем
- **Спорт** — спортивные события и новости
- **Игры** — видеоигры, настольные игры

## 🚀 Запуск проекта

Проект запускается в Docker: PHP, MySQL, phpMyAdmin и все зависимости ставятся внутри контейнеров. Устанавливать PHP, Composer, Node.js или базу данных на компьютер **не нужно**.

### Шаг 1. Установка WSL (только Windows)

1. Нажмите `Win`, введите «Терминал», кликните правой кнопкой → **Запуск от имени администратора**.
2. Вставьте команду и нажмите `Enter`:
   ```
   wsl --install
   ```
3. Дождитесь окончания установки. Если WSL уже установлен, команда просто сообщит об этом — это нормально.

### Шаг 2. Установка Docker Desktop

1. Скачайте Docker Desktop: https://docs.docker.com/desktop/setup/install/windows-install/ (для macOS/Linux — выберите свою систему на той же странице).
2. Установите с настройками по умолчанию (галочка **Use WSL 2 instead of Hyper-V** должна быть включена).
3. **Перезагрузите компьютер.**

### Шаг 3. Первый запуск Docker Desktop

1. Откройте Docker Desktop и примите лицензионное соглашение.
2. Войдите через GitHub (если аккаунта нет — зарегистрируйтесь). Этот шаг можно пропустить кнопкой **Skip** — для запуска проекта вход не обязателен.
3. Дождитесь, пока в левом нижнем углу появится зелёная надпись **Engine running**. Docker Desktop должен оставаться запущенным всё время, пока работает проект.

### Шаг 4. Скачивание проекта

**Вариант А — через Git:**
1. Выберите папку, куда хотите сохранить проект, зайдите в vs code, выберите выбранную папку, откройте терминал через " ctrl + ` " и введите команду:
```
git clone https://github.com/Dinnoise/ForMinds.git
```

**Вариант Б — без Git:** на странице https://github.com/Dinnoise/ForMinds нажмите **Code → Download ZIP**, распакуйте архив и откройте папку проекта.

### Шаг 5. Открытие терминала в папке проекта

Откройте папку проекта в Проводнике (там, где лежат файлы `docker-compose.yml` и `Dockerfile`), кликните правой кнопкой по пустому месту → **Открыть в Терминале**.

Проверить, что Docker доступен:
```
docker --version
```
Должна вывестись версия, например `Docker version 29.x.x`.

### Шаг 6. Запуск

```
docker compose up -d --build
```

Первый запуск занимает **5–10 минут**: скачиваются образы и устанавливаются зависимости. Следующие запуски — несколько секунд.

После того как команда завершится, приложению нужно ещё ~30 секунд, чтобы применить миграции и заполнить базу. Следить за этим можно так:
```
docker compose logs -f app
```
Когда появится строка `Development Server (http://0.0.0.0:8000) started`, всё готово. Выйти из просмотра логов — `Ctrl + C` (проект при этом продолжит работать).

### Полезные команды

| Действие | Команда |
|----------|---------|
| Остановить проект | `docker compose down` |
| Запустить снова | `docker compose up -d` |
| Пересобрать после изменений в коде | `docker compose up -d --build` |
| Посмотреть логи | `docker compose logs -f app` |
| Выполнить artisan-команду | `docker compose exec app php artisan <команда>` |
| Удалить базу и начать с нуля | `docker compose down -v`, затем `docker compose up -d --build` |

> Изменения в коде **не подхватываются автоматически** — после правок выполните `docker compose up -d --build`.

### Возможные проблемы

- **`docker: command not found` / `docker` не является командой** — Docker Desktop не запущен или компьютер не перезагружен после установки.
- **Docker Desktop пишет про WSL или виртуализацию** — выполните в терминале от администратора `wsl --update` и перезагрузитесь. Если не помогло — включите виртуализацию (Intel VT-x / AMD SVM) в BIOS.
- **`port is already allocated` (порт 8000, 8080 или 3307 занят)** — остановите программу, которая занимает порт (например, локальный MySQL или Apache из XAMPP), или поменяйте левую часть порта в `docker-compose.yml`, например `"8001:8000"`, и откройте http://localhost:8001.
- **Сайт не открывается сразу после запуска** — подождите 30–60 секунд и проверьте логи: `docker compose logs app`.
- **Ошибка 500 на сайте** — посмотрите лог Laravel: `docker compose exec app cat storage/logs/laravel.log`.
